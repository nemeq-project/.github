# Nemeq

**N**atural **E**mbodied **M**ulti-agent **E**cosystem for **Q**uoriosity

An open-source ecosystem for embodied AI agents. Animas, bodies, embodiments — 
and a built-in mechanism that makes agents act only when their curiosity is 
confirmed by a sufficient quorum of independent grounds.

## What is Nemeq

- **Animas** (Zi) — portable packages of skills, knowledge and style
- **Bodies** (Su) — environments where animas live
- **Embodiments** (Tush) — an anima's life in one body, across many incarnations
- **Incarnations** (Shanu) — one run inside an embodiment, a counter not an entity
- **Quoriosity** — the principle: no action without verified independent grounds

## Why Nemeq

Most agent frameworks treat the agent as a prompt with tools. Nemeq treats it 
as a full system: an anima that can be packaged and sold, a body that provides 
the environment, and an embodiment that carries memory across runs.

Quoriosity is what makes it trustworthy: the agent asks and acts only when 
its curiosity is confirmed by a sufficient quorum of independent grounds. 
No blind consensus, no silent hallucination — a minority report is always kept.
